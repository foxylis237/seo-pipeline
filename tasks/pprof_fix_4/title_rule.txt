# Правило переименования: пары «было — стало». Пар может быть несколько.
#
# Из каждой пары выводится замена подстроки: общее начало и общий конец отбрасываются,
# изменившаяся середина расширяется до целых слов и становится правилом. Здесь их два, потому
# что в пачке встречаются оба написания — со «ФИС» и без него:
#
#   «в ФИС ФРДО» → «сведений в ЕГИСЗ»
#   «в ФРДО»     → «сведений в ЕГИСЗ»
#
# Порядок строк значения не имеет: длинный якорь всегда проверяется раньше короткого, иначе
# «в ФРДО» откусывало бы хвост у «в ФИС ФРДО».
#
# Правила применяются к названию записи, к видимому заголовку страницы (поле prof_title) и к
# SEO-заголовку. Заголовок, к которому не подошло ни одно, останавливает статью с внятной
# ошибкой — молча пропустить переименование нельзя. Уже переименованный остаётся как есть:
# повторный прогон не делает «сведений в ЕГИСЗ сведений в ЕГИСЗ».
#
# Города правила не трогают: «… в ФИС ФРДО в Москве» станет «… сведений в ЕГИСЗ в Москве».
# Если город надо убирать — добавьте сюда третью пару, показывающую это на примере.
#
# Проверить, что правила сработают на всей пачке, до единой правки в блоге:
#   make pprof-fix-4 run plan

было: Периодическая аккредитация врачей с внесением в ФИС ФРДО
стало: Периодическая аккредитация врачей с внесением сведений в ЕГИСЗ

было: Периодическая аккредитация врачей с внесением в ФРДО
