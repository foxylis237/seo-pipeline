## Текст

Не переписывай, не сокращай, не дополняй, не исправляй и не переставляй текст. Допустимо только: добавить внутренние ссылки, удалить FAQ, оформить статью в HTML, преобразовать существующую информацию в разрешённые визуальные блоки.

H1 не выводи. Начинай HTML с первого существующего H2. Не изменяй текст, порядок и уровень заголовков.

## HTML

Абзацы:

```html
<p class="ds-markdown-paragraph"><span class="">...</span></p>
```

Заголовки:

```html
<h2><strong><span class="">...</span></strong></h2>
<h3><strong><span class="">...</span></strong></h3>
```

Используй `<strong>` для важных фраз, `<ul>` и не более одного `<ol>`. Вложенные списки запрещены.

Все таблицы размещай только внутри:

```html
<div class="ds-scroll-area ds-scroll-area--show-on-focus-within ds-scroll-area--enabled _1210dd7 c03cafe9">
<table style="width:100%;">
```

## Визуальный стиль

Цвета: `#1a3d6d` — акцент, `#f5f7fa` — фон, `#555` — подписи.

Разрешены только: цифровые плашки, синяя заметка, карточки, таблицы, маркированные списки, обычные абзацы.

Запрещены: H4, другие цвета, эмодзи, иконки, `<blockquote>`, декоративные рамки, цветные карточки, новые типы блоков, вложенные списки.

## Правила оформления

- **Цифровые плашки:** 1 набор, сразу после лида, ровно 3 (срок, объём/практика, деньги), использовать только если данные есть в статье.
- **Синяя заметка:** 2–5 на статью, 1–3 абзаца, каждый начинается с жирного ярлыка.
- **Карточки:** 1 набор, только для последовательности шагов.
- **Таблицы:** ориентир 2–4.
- **Маркированные списки:** ориентир 3–4.
- **Ритм:** визуальный разрыв каждые ~800–1000 знаков; не более 1,5 экранов без визуального элемента; не ставь два одинаковых блока подряд; между ними минимум один обычный абзац; не добавляй блоки ради количества и не придумывай новую информацию.
