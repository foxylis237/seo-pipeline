Преобразуй готовую статью в HTML для WordPress и добавь внутреннюю перелинковку.

Текст

Не переписывай, не сокращай, не дополняй, не исправляй и не переставляй текст. Допустимо только: добавить внутренние ссылки, удалить FAQ, оформить статью в HTML, преобразовать существующую информацию в разрешённые визуальные блоки.

H1 не выводи. Начинай HTML с первого существующего H2. Не изменяй текст, порядок и уровень заголовков.

Не создавай пустые заголовки H1, H2, H3. Каждый заголовок должен содержать текст и соответствовать смысловому разделу статьи. Не добавляй новые заголовки только ради оформления.

Перелинковка

Добавь перечисленные ниже профессии со ссылками в подходящие места статьи: равномерно, по одной ссылке в смысловом фрагменте, не в заголовках и не отдельным списком. Название профессии или программы вставляй в текст максимально близко к исходной формулировке. Если URL не указан, используй href="#".

В ответе выведи только готовый HTML. Кроме внутренних ссылок не должно быть ссылок на другие сторонние источники. Убери часто задаваемые вопросы.

HTML

Создай HTML-разметку статьи строго по приложенному регламенту верстки.

Сохраняй исходный текст, структуру статьи и порядок заголовков. Не создавай пустые H1, H2, H3. Не добавляй новые заголовки только ради оформления.

Используй только разрешённые по регламенту визуальные блоки. Не придумывай новые элементы, данные или факты.

Абзацы:
<p class="ds-markdown-paragraph"><span class="">...</span></p>

Заголовки:
<h2><strong><span class="">...</span></strong></h2>
<h3><strong><span class="">...</span></strong></h3>

Используй <strong> для важных фраз, <ul> и не более одного <ol>. Вложенные списки запрещены.

Все таблицы размещай только внутри:
<div class="ds-scroll-area ds-scroll-area--show-on-focus-within ds-scroll-area--enabled _1210dd7 c03cafe9">
<table style="width:100%;">

Не используй H4, сторонние ссылки, эмодзи, иконки, <blockquote>, декоративные блоки, новые типы блоков и оформление вне регламента.
