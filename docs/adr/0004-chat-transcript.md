# ADR-0004. Диалог через транскрипт поверх stateless-провайдеров

**Статус:** принято · **подлежит пересмотру**
**Затрагивает:** `StageChatFactory`, `stageChat` в `internal/llm/llm.go`

## Контекст

Стадии `article` и `info` должны выполняться в одном диалоге: метаданные (`info`) генерируются
с учётом уже написанного текста статьи, а не по исходным данным заново.

При этом маршрутизация допускает fallback между провайдерами (см. [ADR-0005](0005-target-fallback.md)):
стадия `article` может уйти на Gemini, а `info` — на OpenRouter. Нативная сессия чата привязана
к конкретному клиенту и при переключении провайдера теряется вместе с историей.

## Решение

`StageChatFactory` эмулирует диалог поверх stateless-вызовов: история сообщений хранится
на стороне роутера и при каждом обращении склеивается в один текстовый транскрипт вида

```
system-промпт стадии

assistant:
<предыдущий ответ>

user:
<новый запрос>
```

Транскрипт отправляется как обычный одиночный prompt. История переживает смену провайдера,
потому что не принадлежит ни одному из них.

## Последствия

- Fallback между провайдерами работает и посреди диалога — история не теряется.
- Один код диалога на все провайдеры; добавление провайдера не требует реализации чата.
- Цена: с каждым сообщением растёт число входных токенов — история отправляется целиком.
- Модель видит историю как текст, а не как размеченные роли. Для двух шагов приемлемо,
  для длинного диалога хуже нативного формата.
- Побочный эффект: нативные `NewChat` у клиентов (`gemini`, `openai_compatible`) не
  вызываются и стали мёртвым кодом. См. H4 в [бэклоге аудита](../AUDIT-2026-08.md).

## Альтернативы

- **Нативный stateful-чат провайдера** — дешевле по токенам и точнее по разметке ролей,
  но ломается при fallback и требует реализации на каждого провайдера.
- **Гибрид**: нативный чат, пока провайдер не менялся; транскрипт как запасной путь при
  fallback. Сложнее, но снимает главный минус.

## Почему подлежит пересмотру

Решение принималось, когда диалог был один и короткий. Если диалоговых стадий станет больше
или история удлинится, рост стоимости токенов станет заметным — тогда гибридный вариант
окупится. Пока пересматривать преждевременно.
