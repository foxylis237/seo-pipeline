# Регламент вёрстки pprof_2

Сюда кладётся ровно один PDF с регламентом HTML-разметки. Имя файла не фиксируется — значим
каталог: его называет `attachments_dir` стадии `html` в `config/pprof_2.yaml`.

Файл уходит в чат 3 вложением, а не текстом промпта: регламент длинный, и место ему в
приложении к сообщению, а не в самом сообщении.

Двух PDF здесь быть не должно: какой из них уйдёт в модель, станет случайностью.

Регламент свой у задачи, а не общий с pprof_1: у той статьи блога, здесь коммерческие
страницы услуг, и требования к разметке расходятся.
