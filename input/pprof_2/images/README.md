# Обложки страниц

Сюда кладутся картинки, которые уходят в WordPress изображением записи (post thumbnail).

Имя файла — `external_id` страницы, то есть колонка `id` из книги импорта:

```
input/pprof_2/images/1.webp
input/pprof_2/images/5.webp
```

Форматы: `.webp` (основной), `.jpg`, `.jpeg`, `.png`. Если у одной страницы лежит несколько
файлов, берётся первый по этому порядку. Потолок — 32 МБ, но настоящий предел ставит сама
площадка (`upload_max_filesize` и `post_max_size` в PHP), и он обычно ниже.

В медиабиблиотеку файл уходит под slug'ом страницы (`image_slug` из книги импорта), а не под
именем с диска: адрес картинки виден в выдаче, и `1.webp` там — потерянные ключевые слова.

Публикация pprof_2 в блог ещё не настроена — площадку задают переменные `PPROF_2_WORDPRESS_*`.
Обложки нужны именно ей, и класть их можно заранее.

Сами картинки в git не попадают (`.gitignore`), в репозитории остаётся только этот файл.
