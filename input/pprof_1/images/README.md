# Обложки статей

Сюда кладутся картинки, которые уходят в WordPress изображением записи (post thumbnail).

Имя файла — `external_id` статьи, то есть колонка `id` из книги импорта:

```
input/pprof_1/images/19.webp
input/pprof_1/images/37.webp
```

Форматы: `.webp` (основной), `.jpg`, `.jpeg`, `.png`. Если у одной статьи лежит несколько
файлов, берётся первый по этому порядку. Потолок — 32 МБ, но настоящий предел ставит сама
площадка (`upload_max_filesize` и `post_max_size` в PHP), и он обычно ниже.

Публикация без обложки не начинается: `make pprof-1 publish <id>` отказывается до первого
запроса в WordPress, а `make pprof-1 publish plan <id>` показывает, какой файл будет отправлен.

В медиабиблиотеку файл уходит под slug'ом статьи (`image_slug` из книги импорта), а не под
именем с диска: адрес картинки виден в выдаче, и `19.webp` там — потерянные ключевые слова.
Идентификатор вложения нигде не сохраняется — он нужен ровно на время создания записи.

Сами картинки в git не попадают (`.gitignore`), в репозитории остаётся только этот файл.
