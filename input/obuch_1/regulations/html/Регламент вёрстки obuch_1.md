# Регламент вёрстки статьи блога «Обучим Специалиста»

Документ описывает, как выглядит готовая HTML-разметка статьи для этой площадки. Он один на
все статьи блога: правила здесь не зависят ни от темы, ни от профессии. В сообщении приходит
только задача и данные конкретной статьи — текст, список программ для перелинковки.

## Главное правило

**В теле статьи нет ни одного атрибута `style` и ни одного `<div>`.** Оформление несут классы
темы, перечисленные ниже, и только они.

Инлайновые стили на странице есть, но их ставит код после вёрстки — по своим шаблонам, в
фирменном оранжевом площадки. Код оформляет: врезку, ряд плашек, шаги, таблицу, строку
источника, пары «вопрос — ответ» в FAQ и карточку призыва в конце статьи. Задача вёрстки —
разметить текст так, чтобы код узнал эти места. Своего оформления к ним добавлять не нужно:
оно будет снято чисткой, а блок останется без вида.

## Теги и классы

Абзац:

```html
<p class="wp-block-paragraph">...</p>
```

Заголовки:

```html
<h2 class="wp-block-heading">...</h2>
<h3 class="wp-block-heading">...</h3>
<h4 class="wp-block-heading">...</h4>
```

`<strong>` внутри заголовка запрещён: заголовок и так выделен темой. `<span>` не используется
вовсе. Заголовок H1 в разметке не выводится ни тегом, ни текстом — его рисует блог из своего
поля.

Списки:

```html
<ul class="wp-block-list"><li>...</li></ul>
```

Строка списка вида «- **Ярлык.** текст» верстается как `<li><strong>Ярлык.</strong> текст</li>`.
`<ol class="wp-block-list">` — нумерованный список. Их на статью не больше двух: раздел
частых вопросов и, если он есть, ряд шагов `sp-steps`. Вложенные списки запрещены.
`<strong>` используется для важных фраз внутри текста.

## Визуальные блоки

В тексте статьи автор оставляет строки-маркеры. Каждая переводится в блок: ничего не
пропуская и ничего не добавляя от себя. Своих блоков вёрстка не изобретает — нет маркера,
нет блока.

**Класс блока обязателен.** По нему код узнаёт блок и разворачивает его в оформление
площадки. Без класса врезка останется обычной цитатой, а ряд плашек — обычным списком:
отличить их от рядового списка с жирными зачинами нечем.

Строка «ЗАМЕТКА: Ярлык. Текст» — цитата с классом `sp-note`:

```html
<blockquote class="wp-block-quote sp-note">
<p class="wp-block-paragraph"><strong>Из практики.</strong> Текст заметки.</p>
</blockquote>
```

Строка «ПЛАШКИ: значение | подпись ;; значение | подпись ;; значение | подпись» — список с
классом `sp-stats`. Значение короткое: срок, диапазон разрядов, сумма. Подпись — три-пять
слов:

```html
<ul class="wp-block-list sp-stats"><li><strong>2–4 мес.</strong> — срок подготовки по профессии.</li></ul>
```

Строка «ШАГИ: 1) ... ;; 2) ... ;; 3) ...» — нумерованный список с классом `sp-steps`. Номера
рисует код, поэтому «Шаг 1.» внутри строки не обязателен:

```html
<ol class="wp-block-list sp-steps"><li><strong>Медкнижка.</strong> Оформляется до курсов.</li></ol>
```

Сама строка-маркер («ЗАМЕТКА:», «ПЛАШКИ:», «ШАГИ:») в готовой разметке не остаётся ни в каком
виде — ни текстом, ни внутри блока.

Два одинаковых блока подряд не ставятся: между ними минимум один абзац прозы. После заголовка
первым идёт абзац, а не блок. Блоки не ставятся внутри таблиц и списков.

## Таблица

Таблиц в статье 2–3, и каждая оформляется только так:

```html
<figure class="wp-block-table"><table class="has-fixed-layout">
<thead><tr><td><strong>Заголовок</strong></td><td><strong>Заголовок</strong></td></tr></thead>
<tbody><tr><td><strong>Первая ячейка</strong></td><td>значение</td></tr></tbody>
</table></figure>
```

Столбцов два; три — если таблица сравнивает две профессии или даёт заработок по ступеням.
Шапка идёт ячейками `<td><strong>`, а не `<th>`: так свёрстаны все таблицы этой площадки.
Первая ячейка строки жирная. Обёртки `<div>` вокруг таблицы нет — прокрутку на телефоне
дописывает код.

**Таблица плюсов и минусов помечается классом** — `<figure class="wp-block-table sp-proscons">`.
Метка обязательна: по ней код не делает первую колонку жирной. Первая ячейка в этой таблице —
не заголовок строки, а половина разбора, и без метки левая колонка уходит в блог целиком
жирной, а правая обычной. Отличить её от таблицы ступеней по форме нечем — обе в два столбца.

Ячейка в ней длинная — номер, жирный ярлык и одно-два предложения. Размечается она тем же
тегом, что и остальные: ярлык внутри ячейки идёт `<strong>`, абзацев `<p>` внутри `<td>` нет.

Ни одной ячейки терять нельзя, строки местами не меняются, и ни одна таблица статьи не
пропускается: их в тексте несколько, и потерянная не восстанавливается ничем.

## Источники

Строки вида «Источник: домен» сохраняются и оформляются ровно так:

```html
<p>Источник: <a href="https://домен/" rel="nofollow noindex noopener" target="_blank">домен</a></p>
```

Адрес собирается из домена, названного в тексте, и ничего к нему не дописывается. Других
внешних ссылок в статье быть не должно: встретилась внешняя ссылка вне такой строки — ссылка
убирается, текст остаётся.

## Раздел частых вопросов

Раздел «Часто задаваемые вопросы (FAQ)» остаётся в теле статьи: на этой площадке он живёт в
самой статье, а не в полях записи. Заголовок у раздела один — его `<h2>`; заголовков внутри
него нет ни одного. Вопросы идут одним нумерованным списком, строка — жирный вопрос, перенос
`<br>`, ответ:

```html
<ol class="wp-block-list">
<li><strong>Берут ли на обучение без опыта?</strong><br>Берут: программа рассчитана на вход
в профессию с нуля, базовое образование значения не имеет.</li>
</ol>
```

Оформление строк дописывает код.

## Конец статьи

Последний раздел — призыв к обучению: заголовок и один абзац. Размечается как обычный
раздел, теми же классами: он часть текста, а не баннер.

**Кнопку под ним рисовать нельзя** — ни тегом `<button>`, ни ссылкой-кнопкой, ни карточкой,
ни картинкой. Карточку с кнопкой ставит код по своему шаблону сразу за этим абзацем, и
нарисованная вёрсткой дала бы на странице две подряд. Последним в разметке идёт абзац раздела
с призывом.

## Чего в разметке не бывает

Эмодзи, иконок, `<style>`, `<script>`, HTML-комментариев, вложенных списков, `<div>`, `<span>`
и любых атрибутов `style`. Классы — только названные выше: `wp-block-paragraph`,
`wp-block-heading`, `wp-block-list`, `wp-block-table`, `wp-block-quote`, плюс метки блоков
`sp-note`, `sp-stats`, `sp-steps`, `sp-proscons`.

Пустых тегов нет: ни `<p></p>`, ни пустых заголовков, ни пустых обёрток. Заголовки не
создаются ради оформления, текст не переписывается, порядок разделов не меняется.
