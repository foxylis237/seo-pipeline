# pprof_fix_8 — точечные правки отдельных страниц

Вход задачи — `input-fix-8.txt`: номер и ссылка на страницу, по строке. Пачки у задачи нет:
страницы приходят по одной, по мере просьб владельца, и номер здесь — просто порядок
поступления.

Что правится — `tasks/pprof_fix_8/prompts/rewrite.txt`: границы правки. Само содержание
правки готовится заранее и лежит в `prepared/`, потому что общего правила на все страницы
у задачи не бывает.

## prepared/

По каталогу на страницу (`<номер>-<слаг>`):

| Файл | Что это |
|---|---|
| `base.html` | тело записи на момент подготовки правки |
| `article.html` | исправленное тело |

Полей записи задача не меняет, поэтому каталога `fields/` и снимка `base_fields.json` у неё
нет.

`make pprof-fix-8 run plan` сверяет снимки с живыми страницами и показывает, что изменится.
`make pprof-fix-8 run` записывает правки в блог — необратимо, прежний текст остаётся только в
`tasks/pprof_fix_8/output/<номер>-<слаг>/original/`.
