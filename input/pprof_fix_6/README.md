# pprof_fix_6 — готовые правки страниц услуг

Вход задачи — `input-fix-6.txt`: номер страницы и ссылка на неё, по строке. Номера те же, что
у аудита `pprof_audit_2`; в пачку вошли страницы 33–113 (страницы до «Машинист крана
(крановщик) 6 разряда» включительно не правятся).

Что правится — `tasks/pprof_fix_6/prompts/rewrite.txt`: часы, срок и цена приводятся к плашкам
страницы, описание обучения — к дистанционному формату. Разметка и заголовки не меняются.

## prepared/

Правки готовятся заранее, по каталогу на страницу (`<номер>-<слаг>`):

| Файл | Что это |
|---|---|
| `base.html` | тело записи, по которому готовилась правка (снимок аудита) |
| `article.html` | исправленное тело |
| `base_fields.json` | поля записи на момент подготовки |
| `fields/faq_loop_N_faq_*.html` | вопрос или ответ FAQ; файл, совпавший со снимком, не отправляется |

`make pprof-fix-6 run plan` сверяет снимки с живыми страницами и показывает, что изменится.
`make pprof-fix-6 run` записывает правки в блог — необратимо, прежний текст остаётся только в
`tasks/pprof_fix_6/output/<номер>-<слаг>/original/`.
