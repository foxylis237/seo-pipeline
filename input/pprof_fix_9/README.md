# pprof_fix_9 — новый финал с карточкой ДПО ПРОФ у статей pprof_1

Вход — `input-fix-9.txt`: номер статьи pprof_1 (`external_id`) и её адрес в блоге, по строке.
В пачке все 88 статей, опубликованных задачей `pprof_1` до появления карточки призыва.

Что правится: последний раздел статьи становится финалом той же формы, что теперь ставит
генерация `pprof_1` — H2-призыв с «в ДПО ПРОФ» на конце, один абзац и под ним карточка по
шаблону `tasks/pprof_1/templates/cta_card.html` с кнопкой на адрес из колонки `course_url`
книги `pprof_1`. Если последний раздел содержательный, он остаётся, а финал встаёт после.
Название записи, адрес и поля не меняются.

необратимо, прежний текст остаётся только в `tasks/pprof_fix_9/output/<номер>-<слаг>/original/`.
